# SeumLeaderboardFilter

Плагин для **SEUM: Speedrunners from Hell**, который убирает из таблицы
рекордов записи известных читеров, явные портал-стораджи и мягкие
пауэрап-отрывы в самом верху.

Работает через Harmony-патч поверх оригинальной `Assembly-CSharp.dll` —
подменять файлы игры не нужно.

## Что фильтруется

Три независимые причины убрать строку:

1. **Игрок в чёрном списке.** Убираются **все** его записи, на любом месте.
   Если keaz первый, а bruh второй — исчезнут оба, а не только #1.
2. **Портал-сторадж на глобальной доске.** Запись не длиннее `600 мс`, и
   следующий по времени результат минимум в 2 раза медленнее. Это ловит
   результаты вида `0.500` против `1.049`, но не трогает легитимные короткие
   уровни: Hill RR `0.500 → 0.516`, Easy Dizzy RR `0.500 → 0.516`,
   Hop RR `0.566 → 0.571` и т.п.
3. **Мягкий пауэрап-отрыв в топе.** Сравниваем #1 со следующим различимым
   временем: нужно одновременно **≥18%** и **≥1000 мс** отрыва. Если #1
   подошёл, проверяем #2 к #3 и так далее, пока цепочка не оборвётся. Так
   `1.924 → 4.493` (2569 мс, 57%) и `6.171 → 7.556` (1385 мс, 18.3%) уходят,
   а Pyramid RR `10.783 → 11.600` (817 мс, 7%), Dominoes `2.783 → 3.016`
   (233 мс, 7.7%) и Satan RR `21.516 → 22.000` (484 мс, 2.2%) остаются.
   Цепочка не перепрыгивает первый чистый результат, поэтому легитимный #2
   не утаскивается за подозрительным #1.

Портал-правило проверяется **построчно, а не по игроку**: у не-ЧС-игрока
убираются только те строки, которые сами попали под условие, остальные его
результаты остаются. В кластере `500, 533, 1016` уйдёт `500`, а `533` может
остаться: для неё следующий результат — уже `1016`, а это меньше `2 × 533`.
Убирать весь кластер целиком нельзя: на Hill RR и Easy Dizzy RR есть длинные
легитимные кластеры `500–600`, после которых идёт более медленный результат,
и правило «весь кластер» сносит десятки живых строк (на дампе — 229).

`Score.place` на глобальной доске **перенумеровывается**: если скрыт #1,
следующая видимая строка становится #1, а не «#2 без первого места». Это
делается только когда загрузка действительно начинается с первого места.
Списки «вокруг игрока» и «друзья», а также кастомный диапазон VelocityMeter,
открытый не с #1, сохраняют настоящие глобальные ранги. Отключается через
`RenumberGlobal = false`.

Мягкое правило по отрыву — именно мягкое: на дампе оно добавляет 20 строк,
в основном к уже известным читерам и крупным разрывам вроде
`Death From Above 4.417 → 13.959`. Если начнёт задевать живые рекорды,
подними `TopGapPercent` до `0.20`–`0.25` или выключи `HideTopGap`; перед
включением полезно посмотреть `DryRun`.

## Чёрный список

Файл создаётся при первом запуске:

```
<папка игры>\BepInEx\config\SeumLeaderboardFilter.blacklist.txt
```

Формат — один SteamID64 на строку, можно с комментарием после `#`:

```
76561198351858610  # keaz
76561198336109574  # bruh
```

Эти двое лежат по умолчанию. Файл перечитывается на следующем скачивании
лидерборда — перезапуск игры не нужен. Если файл удалить, список очистится.

Dempsey в чёрный список **не входит**: у него сторадж — конкретный результат
`0.500` на Gravity Swapper / Roar, а не все забеги. Этот результат ловится
портал-правилом. Если правило выключить, его `0.500` снова станет видимым.

## Настройки

`BepInEx/config/SeumLeaderboardFilter.cfg` создаётся автоматически.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | Общий выключатель; при `false` патч не применяется. |
| `DryRun` | `false` | Только писать в лог, кого бы скрыли, но не трогать таблицу. Удобно для проверки. |
| `LogHidden` | `true` | Писать в лог каждую скрытую запись. |
| `NeverHideSelf` | `true` | Никогда не скрывать свои собственные скоры. |
| `RenumberGlobal` | `true` | Перенумеровывать глобальный топ 1..N после скрытия строк. |
| `HidePortalStorage` | `true` | Включить правило портал-стораджа. |
| `PortalMaxMs` | `600` | Верхняя граница времени для правила, мс. |
| `PortalRatio` | `2.0` | Во сколько раз следующий результат должен быть медленнее. |
| `HideTopGap` | `true` | Включить мягкое правило пауэрап-отрыва в топе. |
| `TopGapPercent` | `0.18` | Минимальный относительный отрыв (18%). |
| `TopGapMinMs` | `1000` | Минимальный абсолютный отрыв, мс. |
| `TopGapChain` | `true` | Проверять #2 к #3 и далее, пока цепочка не оборвётся. |
| `BlacklistFile` | `SeumLeaderboardFilter.blacklist.txt` | Путь к списку относительно `BepInEx/config`. |

## Как это устроено

Патч — postfix на `SteamDownloadRequest.leaderboardScoresDownloaded`, до того
как `LeaderboardsSteamBackend.update` разложит скачанные записи в
`Leaderboard.scores`. Поэтому фильтр видят все экраны сразу: выбор уровня,
спидрановый селектор, HUD и список реплеев.

Отдельный патч расширяет загрузку. В установленной `Assembly-CSharp.dll` игра
просит у Steam только 15 записей и выделяет `SteamScore[15]`; после скрытия
двух строк показывать было бы нечего, и таблица сокращалась бы до 13 строк.
Плагин поднимает диапазон и лимит `scoreCount` до 50, а массив — до 128, так
что после фильтра остаётся запас для замены скрытых строк. Затем `scoreCount`
уменьшается до **15** видимых: `update` в установленной DLL копирует ровно
`scoreCount` записей в `Leaderboard.scores`, а этот массив всего на 15, поэтому
оставлять там 50 нельзя — иначе `IndexOutOfRangeException`.
Для «друзей» диапазон тоже расширяется; «вокруг игрока» пока остаётся
штатным (4 записи), потому что это отдельное окно вокруг вашей позиции.

Портал- и top-gap правила применяются только к глобальной доске (`type == 0`);
в «вокруг игрока» и «друзья» они не используются, чтобы не судить по неполной
выборке. Чёрный список работает во всех трёх списках.

## Сборка

```bash
dotnet build SeumLeaderboardFilter/SeumLeaderboardFilter.csproj -c Release
```

Путь к managed-сборкам игры задаётся свойством `GameManagedDir`, по умолчанию —
локальная установка Steam:

```
D:\SteamLibrary\steamapps\common\SEUM Speedrunners from Hell\Seum_Data\Managed
```

## Проверка на дампе

По дампу от 25.03.2026 (873 мутаторные доски):

- чёрный список `keaz` + `bruh` убирает 117 записей на всех местах;
- портал-правило добавляет 12 записей (0.500–0.533 против 899+), включая
  Dempsey `0.500` на Gravity Swapper / Roar;
- мягкое top-gap-правило добавляет ещё 20 записей, в основном крупные разрывы
  вроде `Death From Above 4.417 → 13.959` и `Burnt Waffle 13.654 → 21.772`;
  это самый спорный слой, его стоит сначала посмотреть через `DryRun`;
- легитимные верхушки, включая Hill RR `0.500 → 0.516`, Pyramid RR `10.783`,
  Dominoes `2.783 → 3.016` и Satan RR `21.516`, не затрагиваются.
